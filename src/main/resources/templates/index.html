What this demo shows of Evento 3.0

  • Spring Boot starter: the bundle is configured from evento.bundle.* properties (application.properties).
  • Hardened server: the Evento Server runs the prod security profile, with a bus token, TLS, a payload allowlist and a read-only public console.
  • Read your writes: after every action the page is answered only once the projectors have your change (docs).
  • Personal data and the right to erasure: names stored encrypted, Forget me deletes the key (docs).
  • Several events from one command: Check all returns DomainEvents, one event per todo, stored all or none.
  • Paged and streamed queries: the list above is a Page, the CSV export a stream (docs).
  • Payload versioning: TodoListCreatedEvent is at @Revision(1), with an upcaster for the events written before (docs).
  • Test fixtures: the aggregates, the saga and the services are tested given/when/then with evento-test, no server needed.
